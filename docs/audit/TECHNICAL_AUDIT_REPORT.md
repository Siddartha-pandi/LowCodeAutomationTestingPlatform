# Technical Audit Report (Reconciled) — LowCodeAutomationTestingPlatform

## 1. Overall Assessment

Following Version 2 initial remediation and the Phase 2 targeted security, reliability, and infrastructure pass, the platform's core security controls, execution state machine, authorization boundaries, migration framework, and Docker/DevContainer configurations have been systematically hardened and verified via unit tests, TypeScript checks, and production builds.

## 2. Reconciled Findings Ledger

Statuses: `OPEN`, `IN_PROGRESS`, `FIXED`, `VERIFIED`, `PARTIALLY_FIXED`, `NOT_VERIFIED`, `DEFERRED`.

| ID | Severity | Area | Finding | Status | Evidence |
|---|---|---|---|---|---|
| **AUD-001** | CRITICAL | Auth / Controllers | Controllers read `user.userId` (`undefined`) instead of `user.id` (55 call sites across 11 controllers incl. `RecorderController.getStatus`). | **VERIFIED** | `grep -rn "user\.userId" backend/src/` returns 0 matches; `authorization.spec.ts` + `tsc --noEmit` pass. |
| **AUD-002** | CRITICAL | RBAC / Audit | `AuditController` lacked `RbacGuard` and permission decorator. | **VERIFIED** | `@UseGuards(JwtAuthGuard, RbacGuard)` + `@RequirePermissions('users:manage')` in `audit.controller.ts`. |
| **AUD-003** | CRITICAL | Authorization | `SchedulesController` & `SchedulesService` lacked project access checks. | **VERIFIED** | Project checks enforced in `schedules.service.ts`; tested in `authorization.spec.ts`. |
| **AUD-004** | CRITICAL | Authorization | `ReportsController` & `ReportsService` lacked project access checks. | **VERIFIED** | `ProjectsService` injected in `reports.service.ts`; tested in `reports.service.spec.ts` & `authorization.spec.ts`. |
| **AUD-005** | CRITICAL | SSRF / Browser | `InteractiveSessionService` bypassed allowlists for `document`, lacked interception in `startRecorder`/`exploreDom`, and lacked post-redirect checks. | **VERIFIED** | Shared `attachPageSecurityPolicies` & `validateNavigationUrl` (pre-nav + post-redirect) wired across all entry points; tested in `url-security.spec.ts` & `selector-validation.spec.ts`. |
| **AUD-006** | CRITICAL | SSRF / Allowlist | Domain allowlists bypassed private IP/DNS checks; `ActionExecutorService.api_request` only blocked metadata strings; `ALLOW_LOCALHOST_AUTOMATION` lacked production guard. | **VERIFIED** | `url-security.ts` separates allowlist from IP/DNS A+AAAA checks, blocks dev bypass in `NODE_ENV=production`, and validates `api_request`; tested in `url-security.spec.ts`. |
| **AUD-007** | CRITICAL | WebSocket Auth | `MonitoringGateway` had `NODE_ENV=development` unauthenticated bypass and JWT lacked `is_superuser`. | **VERIFIED** | Bypass removed in `monitoring.gateway.ts`; `is_superuser` added to `AuthService.generateToken()`; tested in `monitoring.gateway.spec.ts`. |
| **AUD-008** | HIGH | Artifact Security | `ArtifactsService` skipped path check for absolute paths, lacked symlink check (`realpathSync`), and `ExecutionsService.getExecutionViewportPath` lacked path validation. | **VERIFIED** | `assertWithinStorage` & `resolveSafeViewportPath` enforce `realpathSync` containment; `AuditService.purgeRetention` excludes active executions and unlinks expired files safely; tested in `artifacts.service.spec.ts`. |
| **AUD-009** | HIGH | Config & Secrets | `validateEnvironment` was not wired into `ConfigModule.forRoot`, `app.storage.dir` key mismatch, and static fallback secrets existed in config & `.devcontainer/docker-compose.yml`. | **VERIFIED** | `validate: validateEnvironment` wired in `AppModule` & `WorkerModule`; production rejects weak secrets, `DB_SYNCHRONIZE=true`, and `ALLOW_LOCALHOST_AUTOMATION=true`; tested in `configuration.spec.ts`. |
| **AUD-010** | HIGH | Auth / Reset Token | Plaintext `resetPasswordToken` stored in DB and logged in `forgotPassword()`. | **VERIFIED** | SHA-256 hashed in `auth.service.ts`; raw token removed from logs; tested in `auth.service.spec.ts`. |
| **AUD-011** | HIGH | Execution Reliability | `FlowsService.executeFlow()` double-executed (in-process + BullMQ); cycles not rejected; condition branching didn't skip branches; no execution state machine or bounded execution timeout. | **VERIFIED** | Single-dispatch in `flows.service.ts`; `execution-state.ts` state machine; cycle rejection, branching, cancellation, and timeouts tested in `flow-validation.spec.ts` & `execution-state.spec.ts`. |
| **AUD-012** | HIGH | Frontend Auth & CSRF | Frontend stored JWT in `localStorage`, omitted `credentials: 'include'`, lacked CSRF protection, and `main.ts` allowed arbitrary `localhost` CORS in production. | **VERIFIED** | Migrated to `HttpOnly` cookie + `CsrfMiddleware` double-submit token; removed `localStorage` JWTs & WS `?token=`; CORS restricted in production; tested in `csrf.middleware.spec.ts` & `next build`. |
| **AUD-013** | MEDIUM | WebSocket / Redis | `MonitoringGateway` opened 1 Redis connection per client. | **VERIFIED** | `EventPublisherService` uses a single shared `redisSubscriber` with reference-counted channels and payload redaction; verified via `monitoring.gateway.spec.ts`. |
| **AUD-014** | MEDIUM | Database Migrations | No TypeORM migrations existed; `DB_SYNCHRONIZE` could be enabled in production. | **PARTIALLY_FIXED** | `data-source.ts` and `1732600000000-InitialSchema.ts` created and `synchronize` disabled in production; live execution against PostgreSQL not run in sandbox (`NOT_VERIFIED` at runtime). |
| **AUD-015** | MEDIUM | Docker & DevContainer | Stub `Dockerfile`s, unconditional frontend/backend polling, missing production Compose stack. | **PARTIALLY_FIXED** | Multi-stage `backend/Dockerfile`, `frontend/Dockerfile`, `docker-compose.prod.yml`, and gated polling implemented; `docker build` not executed (Docker CLI unavailable in sandbox). |
| **AUD-016** | LOW | Dead Code | Unused `backend/src/modules/execution/` module and `modules/queue/queue.module.ts` shim. | **DEFERRED** | Left intact for backward reference; not imported in `AppModule`. |
